# Dr. Amit Khandelwal — Executive Leadership & AI Governance Portfolio

> **Digital Transformation & AI Leadership | Certified CAIO | ISO 42001 Lead Implementer | CISO 100 Honoree | Former Global Practice Head & Leader at Capgemini**

An interactive, high-performance executive portfolio highlighting Dr. Amit Khandelwal's career achievements, board advisory mandates, real-time enterprise AI risk calculators, live ISO 42001 governance sandboxes, and verified physical honors and accreditations.

---

## 🚀 Key Features

* **Deterministic Boardroom AI & Risk Calculator**: Interactive executive model projecting tangible balance-sheet protection, audit timelines, and regulatory compliance velocity based on annual enterprise scale (€100M – €2.0B+).
* **ISO 42001 Governance Sandbox**: Dynamic before/after architecture visualizer contrasting unregulated AI topologies against sovereign ISO/IEC 42001 (AIMS) enterprise boundaries.
* **Accreditation & Verification Registry**: 3D tilt physics cards with real-time specular glare on authentic trophies, backed by an institutional modal with one-click certificate credential verification.
* **Multi-Step Guided Mandate Scope Builder**: Comprehensive 3-step advisory mobilization workflow with real-time corporate dossier generation and bilateral mutual NDA execution toggles.
* **Fluid Mobile Responsiveness**: Complete zero-overflow responsiveness tested down to 320px viewports (iPhone SE / Android compact) with 44px minimum tap targets.

## 📦 Getting Started

### Prerequisites
* Node.js version 18.0 or higher
* npm or pnpm package manager

### 1. Installation
```bash
npm install
```

### 2. Local Development
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Production Build
```bash
npm run build
```
Generates production-ready, minified and optimized assets in the `dist/` directory.

### 4. Preview Production Build
```bash
npm run preview
```

## 🌐 Deployment Instructions

### Option A: Vercel (Recommended)
1. Push your repository to GitHub / GitLab / Bitbucket.
2. Import the repository into [Vercel](https://vercel.com).
3. Vercel automatically detects the Vite framework:
   * **Build Command**: `npm run build`
   * **Output Directory**: `dist`
4. Deploy!

### Option B: Netlify
1. Connect your repository on [Netlify](https://netlify.com).
2. Configure build settings:
   * **Build command**: `npm run build`
   * **Publish directory**: `dist`
3. *(Optional)* For client-side routing, ensure `public/_redirects` contains:
   ```
   /*    /index.html   200
   ```

### Option C: Cloudflare Pages
1. Select Cloudflare Pages > Create a project.
2. Connect Git repository.
3. Select **Vite** preset:
   * **Build command**: `npm run build`
   * **Output directory**: `dist`
